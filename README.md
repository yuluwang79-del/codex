# 外协核销工作台

浏览器本地处理 XLSX，按客户＋DD号＋图号匹配，扣除历史后逐笔和跨行分配余量。支持部分核销、无此订单、待核实和两表同步导出。

仅含网页程序及虚构演示数据，不含实际订单或物料表。JSZip 依赖随程序提供并保留原许可证。

## GitHub Pages 发布

免费账户从公开仓库发布；私有仓库需要支持 Pages 的套餐。确认代码可以公开后，在 Settings → General → Danger Zone → Change repository visibility 设置 Public。

然后 Settings → Pages → Deploy from a branch → main → / (root) → Save。以该页面返回的网址为准。国内访问需要实测。

修复前后对比、逐笔坐标和剩余验收事项见 [审阅记录](REVIEW.md)。制造部门不限制厂内加工范围；客户必须一致，可选择或新增客户。纯数字错误历史按行保留跳过，不影响同键其他明确物料。测试目录仅使用虚构数据，真实文件不要提交到公开仓库。

客户列与喷粉消单列分开：客户列只读匹配，原喷粉消单列读取历史并追加本次实际核销。客户选择器禁用消单、数量等业务列；替换另一份文件不会重置已确认映射。原工作簿只改指定核销格，不新增客户列或重建原表。无客户列的分客户工作表可以明确指定客户；订单“厂区”经业务确认可作为客户来源。

对已确认的“厂内工作表名对应订单客户/厂区值”规则，一致且不冲突时自动填好客户来源，直接点“开始核对”即可；不再需要重复点击“应用客户对应”。

默认核对订单文件的全部厂区明细工作表；下拉框用于逐表检查和调整字段。各厂使用同一份客户＋DD号＋图号余量台账，结果逐厂显示条数和件数，导出写回各自原工作表。勾选多个项目时，厂内来源包括这些项目对应的多张工作表；未勾选项目时，按当前厂内工作表处理。

厂区支持单选和多选：取消“全选厂区工作表”，勾选本次要核对的厂区后开始。未勾选页原样保留；自选模式重新上传订单后需要重新勾选，防止沿用旧文件的核对范围。


厂区固定为一厂、二厂、三厂、五厂、六厂、总厂；其他订单页按供应商单独管理。网页支持新增供应商、绑定已有订单工作表，以及新增/选择客户。新增选项保存在当前浏览器，不向原Excel插入行列。新增制作商名称用于本次核销选择及同工序历史占用量识别。默认“厂内”只核所选厂区；选择“达康”等制作商后，处理该制作商订单工作表，其他制作商页保留。

同客户内，用户指定优先行后先核DD号、图号、名称、剩余数量一致的记录，再执行同客户DD号＋图号的整组/整行及跨行数量分配。名称不同不阻止后续消单。缺客户表头时，只有实际列值能唯一对应客户名单才自动识别，多候选必须明确选择。

客户未识别、客户字段有歧义、客户为空或其厂内资料不在本批时，先跳过相关工作表/订单，保留原文、不写“无此订单”、不占用厂内余量，其余客户继续。若全部客户都需后补，返回明确的0新增结果，两份原文件保持不变；后续提供对应客户资料后可另批核对。

项目名称改为勾选列表，可多选一起核对。默认名单按用户截图设置，并列出手动新增项；上传文件不再自动扩充客户选项；“新增项目”只添加选项，不自动勾选，也不改原表“专案名称”（DD号）列。“添加勾选项目到常用名单”仅保存当前浏览器的选项，勾选后可直接开始核对，无需先保存。刷新保留常用名单、清空本次勾选。

选择客户后，读取客户归属一致的厂内工作表以及混合页的对应客户记录。以“海天精工”或“海天塑机”结尾的名称，分别归到该后缀客户；即使已有同名主表，带前缀的分项目页仍一起参与。其他客户仅按原完整名称匹配，不扩大别名规则。多项目、多厂共用余量，仍以实际客户＋DD号＋图号隔离，保留原有名称和数量优先规则。汇总页与明细同时选中时跳过汇总，避免重复扣量。

缺资料项目及缺DD号、图号、数量或核销列的相关表直接跳过，网页列待审核，其余项目继续。结果列出各来源工作表的新增量及逐笔两端原始坐标。未勾选、待审核项目保留原空白和历史；导出只能修改指定核销格。76项自动测试通过，包括多项目实际浏览器上传、导出两表和重传零新增；仓库内测试数据均为虚构，真实文件验证记录仅私下交付。

本次客户默认名单：海天精工、海天塑机、赛尔富、公牛、乐仝、兴泰、埃利、荣特、君灵、东英吉利、蓓灵。可继续手动新增。此前保存的带前缀海天客户选项归并为一个根客户选项，不重复显示。原始工作表名、客户格、DD号与图号不变，分配明细同时展示原客户与核对归属。

海天精工与海天塑机各自隔离，不互借数量；真实客户列优先于页名。没有客户列的已确认客户页也不能被旧手选客户改归属，替换为另一个客户的文件时，所选客户无资料则跳过，待重新勾选该客户。

真实工作簿复测补充：识别“销售订单／销售订单号”作为DD来源，保留“客户订单号”的区别；识别“产品名称／存货名称”以执行名称数量优先。一个格内多个DD号（包括重复写两次）不能通过去换行拼成新DD号，应待核实、保留标注空白，不写“无此订单”。这些校验同时覆盖厂内来源和订单。

匹配证据先读取整本厂内工作簿，未勾选来源只用于区分客户不一致或范围未选，不进入数量分配；避免同键存在于另一客户页时误写“无此订单”。

## 选择厂内、达康或其他制作商

顶部“本次制作商”可选择厂内、达康及其他已添加制作商。下方“其他制作商／供应商”表单可手动新增并保存在当前浏览器；刷新不恢复上批活动选择，默认回厂内。已登记且表头唯一声明的制作商可自动选好，手选优先。

厂内仍按六个厂区页勾选。外协文件允许“达康”“Sheet1”及带厂区、客户前缀的工作表；无本页声明的可见页先继承文件唯一制作商，全文件无声明时才按用户选择，多个制作商且本页归属不明时先保留；其他制作商声明页、未确认归属的隐藏页及汇总页保留。缺DD号或核销列先待审核；“厂内订单号”仅作为含DD值的对应字段，不能把客户订单号、普通品号或名称充作DD。

本次只追加所选制作商的新量，不把原有“厂内”历史改名：物料全核写“10月达康”，部分写“10月达康对X件”，有历史则保留并追加；订单写“10月达康已对”或“10月达康只能对X件”，补对区分本次与累计。选择其他制作商时替换名称。厂内继续原有标注口径。各制作商共用原数量，全部已确认同工序历史先扣一次；只有所选制作商的本月历史进入本批对账。

没有专用核销列但有唯一备注列时，页面提供“用某列备注追加核销（保留原文）”按钮，由用户明确选择；不自动写空白列，不插列、不改表头。普通业务备注原文保留后追加；含未确认历史、异常业务或纯数值的记录保留待核实。

多份外协清单逐份上传，每次接着上一批导出的物料总表核对；不要重新拿未扣量的原始总表开始。导出重传同一文件且表头一致时恢复确认的映射，不套用到另一份不同文件；手选核销年月不会被后上传文件的旧表头覆盖。本次会话识别出的制作商可供后续文件扣历史，长期使用请手动保存该名称。

真实外协文件已私下生成可审阅的逐笔及逐格方案。原表未统一提供核销专列，实际保存需先确认目标格；这与程序的合成数据网页导出及零新增重传测试分开报告。
